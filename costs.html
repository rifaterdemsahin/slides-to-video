⚖️ The distinction that saves the budget

Recurring burn vs one-off spend

The video's argument is a recurring cost argument, not a purchasing decision. An agent that costs $2 to configure and $60/month to run is a subscription you forgot you signed. The video document that explains it cost one seat, once.

💸 Column A · recurring

What the fleet burns

Per-token API calls, per agent, per day. Grows with activity and never appears on an invoice you approved. This is the column the cost curve lives in.

🎬 Column B · one-off

What the video cost

A Workspace seat you may already hold, plus the time to talk to Gemini. No editor, no stock licence bought separately, no camera, no contractor.

💡 The cheap column is the one that explains the expensive column. That asymmetry is the whole point.

🧠 Where the money actually goes

Split every task in the pipeline into one of two buckets before it runs. The bucket decides the cost.

✅ Deterministic · $0 tokens

Rule logic

Conditions, routing, arithmetic, dedupe. If the answer is knowable from the inputs, an LLM is an expensive way to guess it.

✅ Deterministic · $0 tokens

Scraping & extraction

Fetching structured pages on a schedule. Predictable shape, predictable cost — a request, not a reasoning step.

✅ Deterministic · $0 tokens

Templates

Consistent baseline output. Fill the slots with rules; never regenerate a paragraph that never changes.

🔥 Generative · per-token

Reasoning

Reserved for complex decisions — genuinely ambiguous input, judgement calls, novel situations. This is what you are actually buying.

🔥 Generative · per-token

Synthesis

Dynamic prospect qualification, summarising an unruly thread. High value, high variance — cap it.

🔥 Generative · per-token

Guardrails

Strict context-window limits. The cheapest generative call is the one whose input you trimmed before sending it.

🚦 Control

Guardrails that hold the ceiling

Cost governance is not frugality — it is the reason the fleet is allowed to run unsupervised. Six levers, in the order they save the most money.

  • 🧮 Route first, prompt second. Classify the task as deterministic or generative before a model sees it. Every task reclassified as deterministic is a permanent 100% saving on that path.
  • ✂️ Cap the context window. Strict limits per call. Resent history is the silent multiplier — trim it and you cut every downstream call.
  • 🪜 Model laddering. Cheapest model that clears the bar for the task; escalate only on failure. Reasoning models are for reasoning, not for formatting.
  • ♻️ Cache and dedupe. Daily scrapes repeat. Identical input, identical output — serve it from cache instead of buying it twice.
  • 🔁 Budget on retries. A tool loop that fails three times costs three times. Cap iterations per agent per run, hard.
  • 🚦 The human gate. One approval step before any billable action leaves the building. The cheapest agent action is the one a human refuses.
