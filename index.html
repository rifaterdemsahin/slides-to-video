🎯 The whole production line, in four moves. 🚫📷 No camera, 🚫✂️ no editor, 🚫🎞️ no timeline software.

🧠 Create the script with Gemini

Talk. Don't type an outline — dictate the raw brain-dump to Gemini as if you were explaining it to a colleague. Mention the real numbers, the real objections, the real worry.

Then ask one line: rewrite this in a presentation form. Gemini converts the rambling transcript into slide-shaped structure — a title, a subtitle, and 3–4 bolded points per slide.

The source conversation for this video is shared here — note the raw opening ("…I'm going to create them in bulk in one go instead of being one agent at a time, I will create five agents all at the same time because I have around 30 40 50 agents…") sitting right next to the cleaned-up slide script Gemini returned.

🎨 Design the deck — Google Slides, 16:9, dark theme

Paste the slide script into a Google Slides deck set to 16:9 widescreen — that aspect ratio becomes your video frame, so it has to be right at this step.

Keep one visual language across all slides: a monospace all-caps eyebrow label naming the section, a heavy white title, a grey one-line deck, and a small two-bar accent (blue + red) as the sign-off. That restraint is what makes 10 slides read as one film.

Source deck: Scaling AI Agents — Google Slides

🎬 Assemble the video in Google Vids

In Google Vids, import the Slides deck — each slide drops onto the scene timeline as a scene with its own timing. Vids keeps the deck live: edits to the source slides flow back into the scenes.

Then layer on the generated media: an AI voiceover reads the narrator script per scene, a licensed music bed runs underneath, and auto-captions burn the narration in. Vids' Improve sound quality → Balance sound levels speech against music in one click.

Everything sits on a scene timeline with a playhead — 00:00.0 / 02:10.8 — so you fix the video the same way you edit a deck, not the way you edit footage.

🚀 Export, then publish to Skool

Export MP4, commit it to the repo, and enable GitHub Pages on the repo root so this page serves it. Then paste the same content into Skool.

Skool stores classroom lessons as markdown — the lesson URL carries it as ?md=…. So the article you are reading doubles as the lesson body: admin tools → classroom → pick the course → Add lesson → paste → attach the MP4.

See Publish to Skool for the exact destination and the copy-paste block.

⚖️ The two rules that carry the film

💸 Do not spend API dollars on predictable logic.
🔒 Do not spend API dollars on unreviewed output.

The first is cost governance — deterministic work runs on rules, generative calls are reserved for genuine reasoning. The second is accountability — the dashboard's blue dot means a worker has spent money on a billable action nobody has checked yet, and a pink status means a task is waiting on approval. Both are the same discipline: the fleet is allowed to run unsupervised, but not unverified.
